# ESL Crossword Race

A competitive crossword game for ESL classrooms, designed for smartboards. Two teams race to complete their crosswords — the fastest team wins!

## Features

- **Team vs Team**: Two teams play simultaneously on a split-screen layout
- **Teacher Mode**: Create rounds from CSV word/clue lists, freeze worksheets, and print them
- **Tournament Mode**: Play multiple rounds, track wins, and crown a champion
- **Offline-First**: Runs entirely in the browser with no server required — perfect for USB drives
- **Smartboard Optimized**: Large touch targets, 60x60 keyboard keys, no hover states
- **Frozen Rounds**: Lock worksheets so printed copies always match the game layout

## Quick Start

1. Open `index.html` in a browser
2. Enter **Teacher Mode** to create rounds (upload a CSV with `word,clue` pairs)
3. **Freeze** rounds and **Print** worksheets for students
4. Back on the home screen, select a round, set up team names, and hit **Start Game**

## CSV Format

```
hello,a greeting
teacher,a person who helps you learn
book,you read this in class
```
